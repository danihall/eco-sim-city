This project aims to implicitly raise questions about contemporary issues related to the life of a city's citizen.

The goal is to try to subvert the game mechanics of classic city-builders, such as Simcity, to gear the player's decisions toward a sustainable city.

This is reflected in how the data's structure represents a living city; the core idea is that, from a city's data, naturally emerges the issues I want to pinpoint.

I try to present to players the dilemnas of building and managing a city whithin its economic, social and environmental constraints.
